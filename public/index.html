Which model calls the World Cup best?

Seven models get one identical prompt before each match. Forecasts lock at kickoff and are Brier-scored as results arrive.

Leaderboard

Brier score over the three 90-minute outcomes: 0 is a perfect forecast, 0.667 is a know-nothing coin flip, 2 is maximally wrong. Lower is better.

Matches

Probabilities are for the 90-minute result; extra time and penalties count as a draw. Each card shows the consensus of all models, with team-by-team numbers above the bar.

The prompt

Every model receives exactly the same words, with only the fixture filled in. No odds, no news, no hints. Rendered live from the same code that builds the real prompts.
